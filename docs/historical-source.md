# Historical source

The unchanged historical project is [duckycodess/Battle-City](https://github.com/duckycodess/Battle-City). Its inspected revision is 5c9d81cd0de89a05f5946448d19c40fb343b0a2d.

The rebuilt game takes its gameplay brief from the old README, 16×16 stage maps, tile interactions, powerups, cheats, enemy variants, score, and lives. The three layouts and their spawn points are converted into JSON under the content package. No Pyxel runtime code is reused.

The old project has no detected license file. Historical content remains attributed to its repository and revision. Any external art or sound must have explicit source and license metadata before inclusion.
